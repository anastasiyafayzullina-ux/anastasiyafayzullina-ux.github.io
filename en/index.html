Testo Interactive Content Platform 

Each of 5 newsrooms built quizzes and polls in its own admin panel, so every new feature had to be developed several times over.

Designed a single platform for interactive content from scratch, plus a widget that embeds into every newsroom’s website.

Testo User Research 

In 2 years, Testo grew from an MVP into a full-fledged product, and it was no longer clear where to take it next.

Analyzed user session recordings, validated hypotheses with a survey, and prioritized improvements with the dev team using an Impact/Effort matrix.
